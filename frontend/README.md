Zomato Food Reels 🍔

A full-stack food discovery platform inspired by Zomato, where users can explore food through short videos and discover restaurants. Restaurant partners can create profiles and upload food videos to showcase their offerings.

🌐 Live Demo: https://zomato-food-reels-lyart.vercel.app/

💻 GitHub Repository: https://github.com/Ansh12345675/Zomato-food-reels

✨ Features

👤 User Features

- User registration and login
- Explore food through vertically scrollable reels
- Like, comment on, and save food videos
- Discover restaurants through food content
- Visit restaurant profiles
- Responsive user interface
- Bottom navigation: Home, Reels, Saved, and Profile

🏪 Restaurant Partner Features

- Restaurant partner registration and login
- Dedicated restaurant profile
- Upload food videos to playlists
- Edit restaurant profile photo
- Showcase restaurant information
- Display uploaded food videos
- Visit Store functionality

🛠️ Tech Stack

- Frontend: React.js, Vite
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- Media Storage: ImageKit
- Deployment: Vercel (Frontend), Render (Backend)
- Version Control: Git and GitHub

🚀 Getting Started

1. Clone the repository

git clone https://github.com/Ansh12345675/Zomato-food-reels.git
cd Zomato-food-reels

2. Install dependencies

Install frontend and backend dependencies separately:

cd frontend
npm install

cd ../backend
npm install

3. Configure environment variables

Create the required ".env" file in the backend directory and configure your own credentials.

Required configuration includes:

- MongoDB connection URI
- JWT secret
- ImageKit public key
- ImageKit private key
- ImageKit URL endpoint

Never upload ".env" files, passwords, private keys, or database credentials to GitHub.

4. Run the application

Start the backend and frontend using their respective development scripts configured in their package files.
